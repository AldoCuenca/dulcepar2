¿Cómo consigo el token? (solo la primera vez)
1. Entra a GitHub → toca tu foto de perfil (arriba a la derecha) → Settings.
2. Baja hasta Developer settings (al final del menú izquierdo).
3. Personal access tokens → Fine-grained tokens → Generate new token.
4. Ponle un nombre, en "Repository access" elige Only select repositories y selecciona dulce-par-web.
5. En "Permissions" busca Contents y ponlo en Read and write.
6. Genera el token y cópialo — solo se muestra una vez, guárdalo en un lugar seguro.

🔒 Este token es como una contraseña de tu repositorio: no lo compartas. El panel lo usa solo para hablar directo con GitHub desde tu navegador, no pasa por ningún otro servidor.
